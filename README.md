## Working on right now

<!-- active-projects:start -->
- [Factory](https://github.com/arcitai/factory): I’m building Factory to give software work with agents a modular structure, from understanding the problem to reviewing and delivering the result.
- [The Onlinesourdough Method](https://github.com/onlinesourdough/AIOS-plugin): I built The Onlinesourdough Method to carry useful context, decisions and working methods between AI apps, so each conversation can build on the work that came before.
- [OpenPaperDesign](https://github.com/arcitai/openpaperdesign): I wanted an infinite, editable canvas inside my AI agent’s workspace, where we could work through architecture diagrams, systems and interface designs together without leaving the conversation.

## Useful repos

<!-- useful-projects:start -->
**Tools & experiments**

- [Local AI for Omarchy](https://github.com/gustavonline/omarchy-llama-cpp-local-ai): My setup for running local models on Omarchy with llama.cpp and an optional local Copilot.
- [Codex Bridge](https://github.com/gustavonline/codex-claude-bridge): Use Codex as one workspace across models, conversations, files and tools. The first bridge connects Claude.
- [Local Pi worker](https://github.com/gustavonline/local-ai-pi-worker): A separate local Pi worker for delegating tasks through the command line or native RPC.
- [Power BI for Factory](https://github.com/arcitai/Agentic-PowerBI-System): Power BI foundations, delivery methods and skills. I’m turning it into a module for Factory.

**Community**

- [Pi Desktop](https://github.com/gustavonline/pi-desktop): A desktop app I built for the Pi coding agent. I’ve paused development; community maintainers are welcome.

**Resources**

- [YouTube content](https://github.com/gustavonline/youtube-content): Lessons, notes and useful files from my videos.
- [Portfolio](https://github.com/gustavonline/gustavonline-website): My website, with current projects and ways to get in touch.
